# H-Net probe on the T4 for CrowdGPT: plan (NOT_RUN)

Status: **plan only; nothing in this file has been measured.** Source: Hwang, Wang and Gu, "Dynamic Chunking for End-to-End
Hierarchical Sequence Modeling" (arXiv 2507.07955), read through a summary, not the full text or the code.

## Question

Can a learned, byte-level chunker reduce what HiveMind moves between nodes or spends per token on CrowdGPT (`hivemind/crowd-v1`)
prompts, on a T4? This is a measurement of the released checkpoints, not a training proposal.

## What the paper does and does not support (read in full text, 2026-11-01)

- Appendix F: a 1-stage H-Net with the main network initialised from Llama 3.2 3B and frozen, training only a 4-layer
  Mamba-2 encoder and decoder (dim 1536), MLP adapters and the chunker, with a boundary BCE loss and an embedding-matching
  loss. Cost: 189B bytes (90k steps, batch 256, sequence 8192). Result (Table 8): average accuracy 0.617 against the
  teacher's 0.647, MMLU 0.519 against 0.561. So a backbone can be kept, but at a training cost far beyond the T4 or an
  RTX 2070, and the student is worse than the teacher.
- Compression is 4.5-6 bytes per chunk (1-stage) and about 9 on code (2-stage). A BPE token is already about 4.5 bytes, so
  against a token-level split a 1-stage H-Net crosses the boundary about as often as a tokenizer; the "5x-9x" network saving
  sometimes quoted is relative to raw byte-level routing, which HiveMind does not do.
- The paper does not route chunks to experts; it calls dynamic chunking orthogonal to MoE (Figure 12 compares against a
  byte-level MoE baseline). Chunk-level expert routing is an extrapolation, not a result.
- The authors report training up to 2x slower than an isotropic model, dynamic memory that can overflow on long batches, and
  uneven per-token compute in batched stepping.

## Cheaper concept probe (no T4, no H-Net weights)

The transferable mechanism is the boundary signal itself: cosine similarity between adjacent hidden states. On a small
local Qwen, measure the distribution of adjacent-state cosine on English, French, Python and Lean, test whether low-similarity
positions coincide with token or whitespace boundaries more often than chance, and run the shuffled-bytes negative control.
If the signal is real it can gate when a local model hands a segment to a remote bee; if not, the chunk-level routing idea
is parked without touching the T4. NOT_RUN.

## Decision rule (stated before the run)

Continue to a two-host pipeline-split test only if measurement 1 succeeds, measurement 2 fits in 8 GB, and measurement 4 shows at
least a 2x reduction in boundary bytes against the BPE split on at least two prompt sets. Otherwise record the numbers and park
the idea. The loss comparison in measurement 5 is context only: H-Net and Qwen differ in training data, so it is not a ranking.
