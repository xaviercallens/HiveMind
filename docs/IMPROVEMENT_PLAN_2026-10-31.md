# HiveMind Improvement Plan (2026-10-31)

> Scope: a read-only audit of `main` at `b69a9cc` across six areas (swarm, router/client/CLI, game/economy/lab, core/data/QueenBee/compress, BOINC/security/deploy, tests/CI/scripts/Lean). **No code was changed to produce this plan.** Each work item becomes its own pull request, assigned to a contributor or agent, following the Definition of Done (DoD) and the test described here.

## How to read the status column

- **R (reproduced):** the claim was checked against the code or a run by the author of this plan.
- **A (audit-reported):** an audit agent reports it with evidence. It has not been independently re-run. Confirm before merging a fix.

Priority: **P0** = live security, money or data loss. **P1** = wrong results or misleading public claims. **P2** = quality, maintainability or hygiene. **P3** = cosmetic.

1. **Rotate the owner API key now.** The same key literal is committed in tracked files on `main` (`src/hivemind/router/gateway.py`, `src/hivemind/router/accounts.py`, `src/hivemind/swarm/s32_01_verlet_kepler442b_copilot.py`, `src/hivemind/swarm/s34_04_self_evolving_roadmap_supervisor.py`, `artifacts/antigravity_sdk_10_prs_receipts.json`). Git history keeps the old value, so removal alone does not close the exposure. **R** (located by grep; the unauthenticated path is at `gateway.py:796`).
2. **Audit the live ledger** for usage billed to the owner account from unknown clients since the first commit that introduced the fallback (`77c3fd4`). **A**.
3. **Decide whether to probe live** the exposures listed as "live not checked" below. Probing production is out of scope for this plan without an explicit go-ahead. **R** (policy).
4. **Paper erratum.** Some numbers in the Zenodo paper (vision-MoE VRAM and latency) come from constants or random draws, according to the audit. Decide the erratum wording after IP-17 is confirmed. **A**.
